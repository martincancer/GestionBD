Clase 08 · SQL Server

Procedimientos almacenados
con parámetros de salida

Cómo crear procedimientos que reciben datos de entrada y devuelven un valor calculado o consultado mediante parámetros OUTPUT, sin depender de un conjunto de resultados.

¿Qué es un procedimiento con parámetros de salida?

Un procedimiento almacenado con parámetros de salida en SQL Server es un conjunto de instrucciones SQL precompiladas que puede aceptar parámetros de entrada y devolver valores a través de parámetros de salida.

Como todo procedimiento almacenado, puede recibir parámetros de entrada. La diferencia es que además se declara un parámetro de salida agregando la palabra clave OUTPUT al final. Luego, dentro de la lógica del procedimiento, se asigna el valor que se desea retornar con SET o SELECT @variable = ....
OUT

Parámetro OUTPUT

Se declara junto al tipo de dato y permite que el procedimiento devuelva un valor al código que lo invoca.

AVG

Ejemplo numérico

SP_Promedio calcula el promedio de dos números y lo devuelve por un parámetro de salida.

DB

Ejemplo con tablas

SP_GetCotizacion consulta MonedasCotizaciones y retorna la cotización de una moneda en una fecha.

EXEC

Cómo ejecutarlo

Declarás una variable, ejecutás el procedimiento y mostrás el resultado con SELECT o PRINT.

Parámetro de entrada
  • Envía un valor hacia el procedimiento.
  • Se declara como @nombre TipoDato.
  • Se usa dentro de la lógica del procedimiento.
Parámetro de salida
  • Devuelve un valor desde el procedimiento.
  • Se declara como @nombre TipoDato OUTPUT.
  • Se asigna dentro del procedimiento y se recupera al ejecutar.

Estructura básica

Todo procedimiento con parámetros de salida sigue el mismo esquema: declaración del procedimiento, parámetros de entrada, parámetro OUTPUT y lógica interna que asigna el valor de retorno.

estructura_basica.sql 
CREATE PROCEDURE NombreProcedimiento
    @ParametroEntrada TipoDato,
    @ParametroSalida TipoDato OUTPUT
AS
BEGIN
    -- Lógica del procedimiento
    SET @ParametroSalida = Valor
END

Ejemplo: SP_Promedio

Este primer ejemplo calcula el promedio de dos números y lo devuelve mediante un parámetro de salida. Es útil para entender el mecanismo sin depender todavía de tablas.

Creación del procedimiento

sp_promedio.sql 
CREATE PROCEDURE SP_Promedio
(
 @n1 numeric(10,2),
 @n2 numeric(10,2),
 @resultado numeric(10,2) OUTPUT
)
AS
BEGIN
 SET @resultado = (@n1 + @n2) / 2;
END

Ejecución

Primero declarás una variable para almacenar el dato retornado. Luego ejecutás el procedimiento con EXEC o EXECUTE, pasando los parámetros de entrada y la variable como parámetro de salida. Para ver el resultado usás SELECT o PRINT.

→

→

ejecutar_sp_promedio.sql 
DECLARE @salida numeric(10,2)

EXECUTE SP_Promedio @n1 = 5,
                    @n2 = 6,
                    @resultado = @salida OUTPUT

SELECT @salida;
i
Al ejecutar el procedimiento, la palabra OUTPUT también se escribe al pasar la variable receptora: @resultado = @salida OUTPUT.

Ejemplo con base de datos Empresa

Ahora el procedimiento consulta una tabla real. Obtiene desde MonedasCotizaciones la cotización de una moneda en una fecha específica, recibiendo el id de moneda y la fecha como entrada y devolviendo la cotización como salida.

Creación: SP_GetCotizacion

sp_get_cotizacion.sql 
CREATE PROCEDURE SP_GetCotizacion
(
 @idmoneda int,
 @fecha datetime,
 @cotizacion numeric(10,2) OUTPUT
)
AS
BEGIN
 SELECT @cotizacion = cotizacion
 FROM MonedasCotizaciones
 WHERE fecha = @fecha AND idMoneda = @idmoneda
END

Ejecución

ejecutar_sp_get_cotizacion.sql 
DECLARE @cot_output numeric(10,2)

EXEC SP_GetCotizacion @idmoneda = 2,
                      @fecha = '20200102',
                      @cotizacion = @cot_output OUTPUT

PRINT @cot_output
!
Recordá separar cada parámetro con coma al ejecutar el procedimiento. Si no hay fila que cumpla la condición, el parámetro de salida puede quedar en NULL.

Resumen de la clase

Repaso rápido de la estructura, la creación y la ejecución de un procedimiento almacenado con parámetros de salida.

Al crear
  • Usá CREATE PROCEDURE con nombre y parámetros.
  • Declará los parámetros de entrada con su tipo de dato.
  • Agregá OUTPUT al parámetro que devolverá el valor.
  • Asigná el resultado con SET o SELECT @var = columna.
Al ejecutar
  • Declará una variable para almacenar el valor de retorno.
  • Ejecutá con EXEC o EXECUTE.
  • Pasá los parámetros de entrada y la variable con OUTPUT.
  • Mostrá el resultado con SELECT @variable o PRINT @variable.
