Consultas PIVOT
en SQL Server

Convertí filas en columnas para armar reportes por período, cliente o categoría usando PIVOT estático con subconsulta interna, agregación y lista de valores.

¿Qué es una consulta PIVOT?

PIVOT es un operador de T-SQL que transforma filas en columnas. Es útil cuando tenés datos en formato largo (una fila por evento) y querés verlos en formato ancho (una columna por categoría o período).

Pensalo como una tabla dinámica en Excel: partís de ventas con una fila por fecha y terminás con una fila por cliente y una columna por año, mostrando el total vendido en cada cruce.

Lista estática

Los años o categorías del IN se escriben a mano; un valor nuevo no aparece solo.

Antes del PIVOT
  • Una fila por cada venta del cliente.
  • Columnas: cliente, año, total.
  • Difícil de leer cuando hay muchos períodos.
Después del PIVOT
  • Una fila por cliente.
  • Una columna por cada año del IN.
  • Ideal para reportes comparativos por período.

¿Por qué solo 3 columnas?

El PIVOT necesita exactamente 3 cosas:

razonSocial → la columna que va a agrupar las filas (queda como fila)

año → la columna cuyos valores se van a convertir en columnas

total → el valor que se va a agregar (sumar, promediar, etc.)
Si seleccionás más columnas en el T, el PIVOT las trata como parte del agrupamiento → filas repetidas. ¡Cuidado!

El PIVOT — girando filas en columnas

PIVOT ( SUM(total) FOR año IN ([2018], [2019], [2020], [2021], [2022], [2023]) ) AS pvt

¿Por qué los años van entre corchetes [ ]?
Porque son números, y SQL Server no acepta números como nombres de columnas sin envolverlos en [ ]. Es como ponerles comillas para decirle al motor "esto es un nombre de columna, no un número".
¿Qué pasa con los años que no tienen datos?
Si Librería del Sur no vendió en 2018 → ese año queda en NULL. Se puede reemplazar con ISNULL([2018], 0) si preferís mostrar 0.

Resultado final del SELECT *

Una fila por cliente. Cada año es una columna. Si no hubo ventas ese año → NULL.

Resumen de las 3 partes de un PIVOT

ParteCódigo¿Qué hace?
Subconsulta TSELECT razonSocial, YEAR(fecha), totalPrepara exactamente 3 columnas para el PIVOT
Función de agregaciónSUM(total)Qué hacer con los valores (puede ser SUM, AVG, COUNT, MAX...)
FOR ... INFOR año IN ([2018],...)Qué columna "girar" y qué valores se vuelven columnas
Limitación importante: los años tienen que estar escritos a mano en el IN (lista estática). Si mañana aparece 2024, la consulta no lo muestra automáticamente. Para hacerlo dinámico hay que usar SQL dinámico con EXEC o sp_executesql.

Consulta completa

Esta es la sentencia completa vista en clase: subconsulta T con JOIN a Clientes, PIVOT con SUM y lista estática de años.

ventas_pivot_por_anio.sql 
SELECT *
FROM (
    SELECT c.razonSocial,
           YEAR(v.fecha) AS año,
           v.total AS total
    FROM Ventas v
    INNER JOIN Clientes c ON c.ClienteID = v.ClienteID
) AS T
PIVOT (
    SUM(total)
    FOR año IN (
        [2018], [2019], [2020],
        [2021], [2022], [2023]
    )
) AS pvt
Parte Qué hace
FROM ( ... ) AS T Subconsulta que devuelve las tres columnas necesarias para el PIVOT.
PIVOT ( SUM(total) ... ) Agrega los totales cuando hay más de una venta en el mismo cruce cliente-año.
FOR año IN ([2018], ...) Convierte cada año listado en una columna del resultado.
AS pvt Alias obligatorio del resultado del operador PIVOT.
!
Si necesitás mostrar 0 en lugar de NULL, envolvé el SELECT exterior con ISNULL([2018], 0) (y así para cada columna de año).

Resumen de la clase

Repaso rápido de la estructura del PIVOT estático y los puntos clave para no confundir filas con columnas.

Las 3 columnas del T
  • Columna de agrupación → queda como fila (ej. razonSocial).
  • Columna a pivotear → sus valores pasan a ser columnas (ej. año).
  • Columna a agregar → el dato numérico a sumar o promediar (ej. total).
Errores frecuentes
  • Seleccionar más de 3 columnas en T → filas duplicadas.
  • Olvidar corchetes en años o categorías numéricas.
  • Esperar que aparezcan años nuevos sin actualizar el IN.
  • Confundir NULL con cero cuando no hubo ventas.
